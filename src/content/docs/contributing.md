Contributions to th30d4y projects are made through the standard GitHub pull request workflow.

## General Workflow

1. Fork the repository on GitHub.
2. Create a branch for your change.
3. Make your changes.
4. Open a pull request against the `main` branch.

## Finding Issues

Each project has an issues tracker on GitHub. Open issues are good starting points for contributions.

## BURP-AI

BURP-AI has a `COLLABORATION.md` file in the repository with specific contribution guidelines.

## OpenLearnX

OpenLearnX uses the AGPL-3.0 license. Contributions must be compatible with this license.

## Reporting Security Issues

For security vulnerabilities, check the `SECURITY.md` file in the relevant repository before opening a public issue.

Projects with documented security policies:

- [BURP-AI SECURITY.md](https://github.com/th30d4y/BURP-AI/blob/main/SECURITY.md)
- [OpenLearnX SECURITY.md](https://github.com/th30d4y/OpenLearnX/blob/main/SECURITY.md)

## Code of Conduct

Check individual repository files for any code of conduct or contribution requirements specific to that project.
