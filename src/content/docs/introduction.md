th30d4y is a GitHub organization hosting open-source tools focused on developer productivity, security research, education, and safety technology.

## Projects

The organization currently maintains the following projects:

| Project | Language | Description |
|---------|----------|-------------|
| [ExecuTrace](/projects/executrace) | Python | CLI tool for recording and replaying developer workflows |
| [BURP-AI](/projects/burp-ai) | Python | Burp Suite extension with AI-powered vulnerability detection |
| [OpenLearnX](/projects/openlearnx) | TypeScript | Decentralized learning platform with blockchain certificates |
| [HAST-CMS](/projects/hast-cms) | Astro | Git-based Markdown publishing system |
| [Aval](/projects/aval) | Python | AI-powered women's safety platform |

## Source Code

All repositories are available at [github.com/th30d4y](https://github.com/th30d4y).
